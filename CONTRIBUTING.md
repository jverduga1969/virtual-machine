# Contribuir a Virtual.Machine

¡Gracias por tu interés! Este proyecto es de código abierto y acepta
contribuciones. Antes de empezar, revisa esta guía breve.

---

## Formas de contribuir

No hace falta ser programador para aportar. Todas estas contribuciones
son bienvenidas:

- **Reportar bugs**: abre un *issue* con los pasos para reproducirlo.
- **Proponer mejoras**: abre un *issue* describiendo el caso de uso
  antes de escribir código, para acordar el enfoque.
- **Documentación**: errores en `README.md`, `README_console.md` o
  `CHANGELOG.md`; ejemplos que falten; aclaraciones.
- **Traducciones**: la app está en español. Traducirla a otros idiomas
  es una contribución valiosa.
- **Código**: parches, refactors, tests.

---
